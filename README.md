# EPL GW6 Watchboard

Mobile-first fixture and lineup watchboard for the league's 2026/27 Premier League GW6.

## Files

- `public/index.html`: published website.
- `wrangler.jsonc`: Cloudflare Workers Static Assets configuration.
- `package.json`: local preview and deployment scripts.

## Deploy

Connect this repository to Cloudflare Workers Builds, install dependencies, and run `npm run deploy`.
